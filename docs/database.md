# Database Architecture & Migrations

## 1. Foundation Tables (Phase 1)

### `users`
Represents application learners / users.
- `id` (VARCHAR / UUID, Primary Key)
- `display_name` (VARCHAR(100))
- `timezone` (VARCHAR(50), default 'Asia/Tokyo')
- `locale` (VARCHAR(20), default 'ja-JP')
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)

### `user_settings`
Configurable learner preferences.
- `id` (VARCHAR / UUID, Primary Key)
- `user_id` (VARCHAR / UUID, Foreign Key -> users.id, UNIQUE)
- `theme` (VARCHAR(20), default 'system')
- `language` (VARCHAR(10), default 'ja')
- `timezone` (VARCHAR(50), default 'Asia/Tokyo')
- `default_ai_provider` (VARCHAR(50), default 'gemini')
- `default_ai_model` (VARCHAR(100), default 'gemini-1.5-flash')
- `default_tts_provider` (VARCHAR(50), default 'voicevox')
- `default_stt_provider` (VARCHAR(50), default 'whisper_local')
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)

### `api_credentials`
Secure storage for user-provided LLM / STT / TTS API keys.
- `id` (VARCHAR / UUID, Primary Key)
- `user_id` (VARCHAR / UUID, Foreign Key -> users.id)
- `provider` (VARCHAR(50), e.g. 'gemini', 'groq', 'openrouter')
- `encrypted_secret` (TEXT, encrypted using AES/Fernet)
- `is_enabled` (BOOLEAN, default True)
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)
- *Constraint*: UNIQUE(user_id, provider)

### `personas`
System & custom Japanese conversation partners.
- `id` (VARCHAR / UUID, Primary Key)
- `name` (VARCHAR(100))
- `description` (TEXT)
- `role` (VARCHAR(100))
- `personality` (TEXT)
- `speaking_style` (VARCHAR(100))
- `difficulty` (VARCHAR(20), e.g. 'N5', 'N4', 'N3', 'N2', 'N1')
- `is_system` (BOOLEAN, default False)
- `avatar_url` (VARCHAR(255), nullable)
- `system_prompt` (TEXT, nullable)
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)

### `user_persona_preferences`
Per-user customizations for personas.
- `id` (VARCHAR / UUID, Primary Key)
- `user_id` (VARCHAR / UUID, Foreign Key -> users.id)
- `persona_id` (VARCHAR / UUID, Foreign Key -> personas.id)
- `custom_prompt_addon` (TEXT, nullable)
- `voice_pitch` (FLOAT, default 1.0)
- `voice_speed` (FLOAT, default 1.0)
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)

### `conversation_sessions`
Foundation model for tracking speaking practice sessions.
- `id` (VARCHAR / UUID, Primary Key)
- `user_id` (VARCHAR / UUID, Foreign Key -> users.id)
- `persona_id` (VARCHAR / UUID, Foreign Key -> personas.id)
- `status` (VARCHAR(50), e.g. 'active', 'completed', 'abandoned')
- `started_at` (TIMESTAMP with timezone)
- `ended_at` (TIMESTAMP with timezone, nullable)
- `created_at` (TIMESTAMP with timezone)
- `updated_at` (TIMESTAMP with timezone)

## 2. Alembic Migration Commands
```bash
# Apply migrations to latest version
alembic upgrade head

# Rollback one revision
alembic downgrade -1

# Create new autogenerated revision
alembic revision --autogenerate -m "description_of_change"
```
